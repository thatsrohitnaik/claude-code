# LifePilot Mobile Assets

This directory should contain:
- icon.png (app icon - 1024x1024)
- adaptive-icon.png (adaptive icon - 1024x1024)
- splash.png (splash screen - 1284x2778)
- favicon.png (web favicon)

You can generate these using Expo's asset generator or create placeholder images.
For development, Expo will use default icons if these aren't provided.
